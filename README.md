# One-Star Review of Something Essential

A deadpan one-star review of an everyday essential, written by `main.py`
to `/output/entry.txt`. One line, 94 characters, no exclamation marks.

## The review

> One star. My elbow has a bone called funny, and in my whole life it has never once been funny.

Why the elbow: the field is flooded with sleep, gravity, the sun, water,
oxygen and Mondays. Nobody had filed a complaint about the funny bone —
a body part named funny that has never once been funny. The grievance is
small, true and instantly recognisable, the deadpan holds all the way
through, and the sting lands in the last few words.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The program is fully deterministic: the review is a fixed string, with no
randomness, no network, no clock and no environment input, so two runs
produce byte-identical output.
